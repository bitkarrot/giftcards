## Phase Goal

**As an** LNBits wallet holder, **I want to** attach a branded image design to a gift card with template selection, QR placement, and text styling, **so that** the bare redemption link becomes a recognizable gift card with a printable PNG download.

## Acceptance Criteria

- [ ] Issuer can create a gift card with a design config (template_name, qr_config, text_config) via the API.
- [ ] The branded card image renders the sats amount, recipient name, and sender message on the chosen template with the QR code at the issuer-specified position.
- [ ] The public card image endpoint (`GET /giftcards/api/v1/cards/{token_hash}/image`) returns a PNG via StreamingResponse.
- [ ] The redemption page shows the branded card image when a design config was set; Phase 1 cards without design config show the bare QR fallback.
- [ ] The authenticated printable endpoint (`GET /giftcards/api/v1/cards/{card_id}/print`) returns a 3x-resolution PNG with `Content-Disposition: attachment`.
- [ ] The card list shows a Delivery status column with color-coded badges (not_sent / sent / failed) or an em-dash when no email is set.
- [ ] All image rendering uses `asyncio.to_thread()` — no Pillow calls in async endpoints.
- [ ] QR minimum size of 150px is enforced server-side in the render function.

## Artifacts This Plan Produces

- **migration `m003_branded_delivery`** in `migrations.py` — adds 10 columns to `giftcards.cards` (template_asset_id, template_name, qr_config, text_config, recipient_email, email_status, email_subject, email_body, email_template) and creates `giftcards.magic_links` table with indexes on email and token_hash.

- **class `DeliverRequest`** in `models.py` — Pydantic v1 model with recipient_email, email_mode, subject, body, template fields.
- **function `render_card_image`** in `services.py` — async wrapper that calls `_render_card_image_sync` via `asyncio.to_thread()`.
- **function `_render_card_image_sync`** in `services.py` — synchronous Pillow compositing: load template (asset or bundled fallback), paste QR at normalized position, draw text block with styled font, return PNG bytes.

- **function `_generate_template_fallback`** in `services.py` — generates a simple Pillow template PNG if bundled assets are missing.

- **endpoint `api_card_print`** in `views_api.py` — `GET /api/v1/cards/{card_id}/print`, authenticated via `require_admin_key`, returns 3x PNG with Content-Disposition attachment header.
- **function `update_card_email_status`** in `crud.py` — updates email_status column on a card.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Public internet → card image endpoint | Anyone with the token_hash can call GET /cards/{token_hash}/image; token_hash is already exposed in the public LNURL URL |
| Issuer browser → print endpoint | Authenticated via require_admin_key; only the card's issuer can download printable PNG |
| Extension → LNBits asset system | Template loading calls get_public_asset; if asset is deleted, renderer falls back to bundled template |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-01-01 | Information Disclosure | Card image endpoint | low | accept | token_hash is already in the public LNURL URL; the card image shows the same info as the public redemption page (amount, sender, message). No new information is exposed. |
| T-02-01-02 | Tampering | Design config JSON | medium | mitigate | qr_config and text_config are parsed with json.loads; invalid JSON falls back to DesignConfig defaults. QR size is clamped to max(150, value) server-side to prevent unscannable QR codes. |
| T-02-01-03 | Denial of Service | Image rendering endpoint | medium | mitigate | All Pillow rendering runs in asyncio.to_thread() — does not block the event loop. Template loading is bounded (single asset fetch or bundled file open). |
| T-02-01-04 | Information Disclosure | Print endpoint | low | mitigate | Protected by require_admin_key; only the issuer wallet owner can download. Card ID is not guessable (gc_ + 16 hex chars from token hash). |
| T-02-01-SC | Tampering | Python package installs | high | mitigate | This plan installs no new runtime Python packages; Pillow, pyqrcode, and all other libraries are already in the LNBits core venv. |
