## Post-Session Changes (2026-06-29)

After the GSD workflow completed, the following changes were made during manual testing:

### Architecture Refactor: No Per-Card Wallets
- **Before:** Each gift card created a dedicated LNbits wallet, moved sats issuer→card_wallet at creation, card_wallet→recipient at redemption.
- **After:** Sats stay in the issuer wallet. `pay_and_complete` pays directly from the issuer wallet at redemption time (following the LNbits withdraw extension pattern). `reclaim_card_sats` just credits the issuer wallet back.
- **DB cleanup:** 10 existing card wallets deleted, sats reclaimed to issuer wallet. `card_wallet_id` column kept as nullable (always `None` for new cards).

### Bug Fixes
- **Proxy headers:** Uvicorn needs `--proxy-headers --forwarded-allow-ips '*'` for correct redemption URLs.
- **LNURL route name:** Added `name="giftcards.lnurl_callback"` for `url_for` to work.
- **CallbackUrl scheme:** `CallbackUrl(url, scheme=request.url.scheme)` required by this version of the `lnurl` library.
- **Timezone-aware datetime:** `expires_at` comparison uses `datetime.now(timezone.utc)` not `datetime.now()`.
- **Quasar v2 binding:** `q-input` uses `:model-value` not `:value`.
- **Migration m002:** Added `raw_token` and `redemption_url` columns (user decision to store raw_token for URL reconstruction).
- **DB cleanup:** Deleted 20 bad `apipayments` rows that caused 400 errors on wallet page load.

### Extension Icon
- Added 128x128 PNG icon at `/giftcards/static/image/giftcards.png`.
- Updated `config.json` with `icon` and `tile` fields.
- Updated `installed_extensions` table directly (entry predated config.json change).
