## Phase Goal

**As a** wallet holder, **I want to** upload a CSV file to create variable-amount gift cards in bulk with per-row validation, and edit or delete existing cards with sats reclaim, **so that** I can efficiently issue personalized cards at scale and manage the card lifecycle.

<objective>
Deliver CSV bulk upload with two-phase validation (validate endpoint → create endpoint), card metadata editing (PUT endpoint), and card deletion with sats reclaim (DELETE endpoint). Also delivers the CSV Upload tab UI with per-row validation table, CSV bulk card creation from validated rows, and the edit/delete dialogs in the frontend. This completes the bulk creation feature (CSV path — validation AND creation) and provides the backend endpoints the dashboard UI (Plan 03) will consume for edit/delete.

Purpose: Enables per-recipient personalized bulk issuance and full card lifecycle management.
Output: CSVRow/CSVValidationResult/UpdateCardRequest models, parse_csv/validate_csv_rows/reclaim_sats_and_delete services, POST /validate-csv + PUT /{id} + DELETE /{id} endpoints, CSV Upload tab + edit/delete dialogs in frontend.
</objective>
